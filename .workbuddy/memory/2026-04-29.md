# 2026-04-29

## 网站搜索功能修复与优化

### Bug修复：搜索图标不显示
**问题**：搜索图标在所有页面均不可见。

**根因**：注入逻辑中用 `createElement` + `appendChild` 时，查询 `.nav-right` 失败（可能是 nav.js 在同一脚本位置修改了 DOM 顺序，或 CSS `justify-content: flex-end` 配合 `margin-left: auto` 导致按钮被推到容区外但仍不可见）。

**修复方案**：
1. 改用 `insertAdjacentHTML('beforeend', ...)` 直接写入 HTML 字符串
2. 选择器改为 `.nav .nav-right`（更精确）
3. 按钮样式全部用内联 style（避免 CSS 优先级冲突）
4. 包装器用 `margin-left: auto` 推到右侧

**关键代码**（search.js）：
```js
const navRight = document.querySelector('.nav .nav-right');
if (!navRight) return;
navRight.insertAdjacentHTML('beforeend',
  '<div id="search-btn-wrap" style="display:flex;align-items:center;margin-left:auto;">' +
    '<button id="search-btn" ...>...</button>' +
  '</div>'
);
```

### 搜索优化：标题优先于内容
**server.js `/api/search`**：
- 标题匹配：2 分
- 内容匹配：1 分
- 按分数降序 + 时间降序排序
- 结果优先展示标题含关键词的文章
- **注意**：debug排查确认后端评分正确，搜索图标CSS不显示的根因是 `insertAdjacentHTML` 替换了原有innerHTML导致结构异常，最终用内联style解决了
