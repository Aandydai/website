### 踩坑记录
1. **better-sqlite3 需要编译**：Windows 上需要 Visual Studio 才能编译，改用 sql.js 替代（纯 JS）
2. **sql.js 不支持参数化查询**：不能用 `db.prepare().get()` 语法，需手动替换 `?` 占位符
3. **表别名问题**：sql.js 的 `exec()` 不支持 `FROM posts WHERE ... SELECT posts.*` 中 `posts.*` 带表名访问子查询 `post_id = posts.id` 的写法，改用完整表名
4. **node 命令路径**：PowerShell 中 `cd /d` 不支持，需用 `Set-Location`
5. **端口占用**：3000 端口曾被占用，需先杀掉进程再启动
